## 🧠 Key Concepts Covered

| Concept | Description |
|---|---|
| CNN | Extracts spatial features from images for visual recognition |
| Image Classification | Predicts the category of an image |
| Transfer Learning | Reuses knowledge from a pre-trained model for a new task |
| Object Detection | Identifies objects and locates them using bounding boxes |
| Bounding Box Regression | Predicts or refines object boundary coordinates |
| R-CNN Family | Detects objects using region-based approaches |
| SSD | Performs object detection in a single forward pass |
| YOLO | Detects objects using a single-stage detection approach |
| OpenCV | Provides tools for image processing and computer vision |
| Semantic Segmentation | Assigns a class label to each image pixel |
| Instance Segmentation | Identifies individual object instances at the pixel level |
| IoU and Dice Score | Measure overlap between predicted and ground-truth regions |
